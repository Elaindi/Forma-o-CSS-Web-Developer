Pseudo elemento

Usado para adcionar elementos extras na pagina,sem precisar adicionar no HTML, como por exemplo, adicionar um texto antes ou depois de um elemento.

Identificado por :palavra-chave

Pseudo-elemento ::first-letter

Seleciona a primeira letra de um elemento, podendo ser estilizado.

Propriedades disponíveis

  • color
  • background
  • margin
  • padding
  • border
  • fonte
  • Propriedades de texto
  • font-size
  • font-family
  • text-transform
